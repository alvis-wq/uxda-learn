In **Documents/UXDA-DS/**, create one folder per design system: **DIB**, **Arcnine** and **Template**. Then open each folder in Claude Code, so each one has its own section in the sidebar.

### What to do
1. Create the folder **Documents/UXDA-DS/** if you don't have it yet.
2. Inside it, create three folders: **DIB**, **Arcnine** and **Template**.
3. Open each of the three folders in Claude Code. Each one gets its own section in the sidebar.

### Our three design systems
- **DIB** — find the file in our Figma.
- **Arcnine** — find the file in our Figma.
- **UXDA Design System Template** — [open it in Figma](https://www.figma.com/design/374PbreBmX1o0RkhwnJi1r/UXDA-Design-System-Template-V1?node-id=2368-82)
