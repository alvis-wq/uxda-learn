Open each design system file in Figma, run the **UXDA Design System Cheatsheet** plugin, open the **Health** tab and choose that design system's folder.

### What to do
For each design system — DIB, Arcnine and Template:
1. Open its file in Figma.
2. Run the **UXDA Design System Cheatsheet** plugin.
3. Open the **Health** tab.
4. Choose that design system's folder (for example **Documents/UXDA-DS/DIB** for DIB).

### Our three design systems
- **DIB** — find the file in our Figma.
- **Arcnine** — find the file in our Figma.
- **UXDA Design System Template** — [open it in Figma](https://www.figma.com/design/374PbreBmX1o0RkhwnJi1r/UXDA-Design-System-Template-V1?node-id=2368-82)

### What to send
A screenshot of each health status.
